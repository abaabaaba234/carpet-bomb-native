# 地毯式轰炸默认携带 v0.5.2

v0.5.2 删除“投弹目标前移”选项、配置变量和飞机目标调整代码，恢复游戏原生目标位置。旧配置中的 `forward` 和旧前移预设不再生效。保留炸弹类型、使用次数、每次使用之间的调用冷却和飞鹰返航装填冷却。数量暂固定原版 **1x（每架 20 枚）**，自定义倍率尚未完成。

进入新任务时，通过必带的“补给”附带原生 `CarpetBomb` 战备，不占四个自选槽位。输入为 **↑ → ↑ → ↑ →**。需要 **Bingus Shared Loader v18**，支持 Steam build **25480438** / EXE **1.8.46015.0**。

## 安装与设置

1. 关闭游戏，在 Arsenal / HD2MM 导入 `NativeCarpetBomb_v0.5.2.zip` 替换旧版；若管理器作为另一模组导入，移除旧版，避免同时启用。
2. 启用“核心”，选择次数、每次使用之间的调用冷却、飞鹰返航装填冷却和炸弹类型。对比测试时保留此前选项。
3. 按加载器文档设置启动脚本优先级，先执行 Purge（清除旧部署），再执行 Deploy（部署当前选择），随后重启游戏，让旧核心退出并清理旧前移选项补丁，然后进入新任务。

默认：2 次、15 秒间隔、装填保持原版、原版飞鹰空袭炸弹、原版 1x 数量。

| 选项 | 可选值 |
| --- | --- |
| 使用次数 | 1、2、3、4、5、6、8、10、无限 |
| 调用冷却（每次使用之间） | 0、5、10、15、30、60、120、300、600、900 秒 |
| 飞鹰返航装填冷却 | 保持原版，或 0、5、10、15、30、60、120、150、180、300、600、900 秒 |
| 炸弹类型 | 原版飞鹰空袭炸弹、地毯式轰炸 200 kg、飞鹰 500 kg |
| 投弹数量 | 暂固定原版 1x，每架 20 枚；总数随实际飞机数变化 |

装填冷却用于次数耗尽或手动重新武装时的基础装填时间。游戏中全部携带的飞鹰战备共用这个值；舰船升级仍由游戏计算。“保持原版”不修改该字段。

炸弹选项更换实际弹体及其原生伤害、爆炸和延时配置。200 kg 与空袭炸弹使用相同模型和撞击特效；500 kg 使用自己的资源包和延时爆炸资源。更换弹体后需重启并进入新任务，让资源载入。

## 配置与日志

位置：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CarpetBombNative.log` / `CarpetBombNative.cfg`。

```ini
enabled=1
uses=manager
cooldown=manager
rearm=manager
bomb=manager
bomb_count=manager
```

`manager` 使用部署选项。支持 `uses=1..100` 或 `-1`（无限），`cooldown=0..1800`，`rearm=-1`（原版）或 `0..1800`，`bomb=170/192/239`。缺少键时使用管理器设置。旧 `bomb_count` 数值覆盖会被忽略，实际数量始终保持 20；旧 `forward` 配置同样被忽略。

保存后重新读取。次数和已在进行的计时可能需要新任务才能更新；弹体、资源包更换后应重启游戏。

## 验证与已知限制

原生载荷缺失的组件/实体映射和独立 120 米进场高度沿用此前修复。原有飞鹰记录及游戏弹体配置保留原样。v0.5.1 的 200 kg 和 500 kg 已获用户确认正常投弹；本版删除前移功能，使用原生投弹目标。v0.5.2 冷启动和实际投弹仍待验证，不能把旧版结果当成本版实测。

带自定义数量的 v0.5.0 测试在舰桥出现 GameGuard 1015。提示不能单独确定是哪条路径触发；随后同时停用代码修改和外部内存读取，200 kg /1x 对照运行正常。数量代码写入和附近内存分配实现已移除，自定义倍率尚未交付。

离线检查覆盖三种弹体与资源包、原有飞鹰记录、固定数量、旧配置兼容、原生飞机目标保持不变，以及原有默认携带、冷却和禁用恢复逻辑。36 个独立预设模块、3510 种可选组合不代表全部实机测试。详细证据见 `VALIDATION.json`；联机同步尚待验证。

## 禁用与开发

`enabled=0` 撤销默认携带与本插件拥有的战备字段。实体/组件映射留到进程退出，避免已创建实体持有失效指针。管理器禁用后，清除旧部署、重新部署并重启即可恢复原版。不会修改账户解锁或装备存档。

源码：`src/core.lua`；打包：`python tools/build.py`；离线检查：`python tests/test_runtime.py`。
