# 地毯式轰炸默认携带 v0.5.1

v0.5.1 移除旧的数量代码修改，增加“投弹目标前移”。数量倍率尚未完成，暂固定原版 **1x（每架 20 枚）**。16 组离线检查通过；本版冷启动和 200 kg /1x/前移 80 米实测通过，用户确认信标两侧均有爆炸、覆盖更均匀。500 kg /1x/前移 0 米也已获用户确认正常投弹。

进入新任务时，通过必带的“补给”附带原生 `CarpetBomb` 战备，不占四个自选槽位。输入为 **↑ → ↑ → ↑ →**。需要 **Bingus Shared Loader v18**，支持 Steam build **25480438** / EXE **1.8.46015.0**。

v0.5.2 已因用户报告问题而撤回。本版恢复此前实测的 v0.5.1 核心，运行代码未作新修改。

## 安装与设置

1. 关闭游戏，在 Arsenal / HD2MM 导入 `NativeCarpetBomb_v0.5.1.zip` 替换旧版。
2. 启用“核心”，选择次数、每次使用之间的调用冷却、飞鹰返航装填冷却、炸弹类型和目标前移距离。
3. 按加载器文档设置启动脚本优先级，先 Purge（清除旧部署），再 Deploy（部署当前选择），然后重启游戏，进入新任务。

默认：2 次、15 秒间隔、装填保持原版、原版飞鹰空袭炸弹、原版 1x 数量、目标前移 80 米。前移 80 米已在 200 kg 实测中改善信标两侧覆盖；500 kg 已在前移 0 米下验证正常投弹。

| 选项 | 可选值 |
| --- | --- |
| 使用次数 | 1、2、3、4、5、6、8、10、无限 |
| 调用冷却（每次使用之间） | 0、5、10、15、30、60、120、300、600、900 秒 |
| 飞鹰返航装填冷却 | 保持原版，或 0、5、10、15、30、60、120、150、180、300、600、900 秒 |
| 炸弹类型 | 原版飞鹰空袭炸弹、地毯式轰炸 200 kg、飞鹰 500 kg |
| 投弹数量 | 暂固定原版 1x，每架 20 枚；总数随实际飞机数变化 |
| 投弹目标前移 | 0、40、80、120、160 米 |

装填冷却用于次数耗尽或手动重新武装时的基础装填时间。游戏中全部携带的飞鹰战备共用这个值；舰船升级仍由游戏计算。“保持原版”不修改该字段。

炸弹选项更换实际弹体及其原生伤害、爆炸和延时配置。200 kg 与空袭炸弹使用相同模型和撞击特效；500 kg 使用自己的资源包和延时爆炸资源。更换弹体后需重启并进入新任务，让资源载入。500 kg /1x/前移 0 米已实测正常投弹。

“投弹目标前移”沿飞鹰进场方向调整本战备新出动飞机的目标，用于平衡信标两侧的覆盖。0 米保留原落点。它不移动红色信标、不改变炸弹数量，已出动飞机不重复调整；其他飞鹰战备保留原样。只修改当前飞机的数据，不改写游戏代码。

## 配置与日志

位置：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CarpetBombNative.log` / `CarpetBombNative.cfg`。

```ini
enabled=1
uses=manager
cooldown=manager
rearm=manager
bomb=manager
bomb_count=manager
forward=manager
```

`manager` 使用部署选项。支持 `uses=1..100` 或 `-1`（无限），`cooldown=0..1800`，`rearm=-1`（原版）或 `0..1800`，`bomb=170/192/239`，`forward=0..300` 米。缺少键时使用管理器设置。旧 `bomb_count` 数值覆盖会被忽略，实际数量始终保持 20。

保存后重新读取。次数和已在进行的计时可能需要新任务才能更新；弹体、资源包更换后应重启游戏。前移距离只用于新出动飞机。

## 验证与已知限制

原生载荷缺失的 18 处组件/实体映射和独立 120 米进场高度沿用已验证的修复。原有飞鹰记录及游戏弹体配置保留原样。v0.4.0 的完整包启动、装填配置及恢复已通过；v0.5.0 采用原版数量的 200 kg 已确认正常投弹。

带自定义数量的 v0.5.0 测试在舰桥出现 GameGuard 1015。提示不能单独确定是哪条路径触发；随后同时停用代码修改和外部内存读取，200 kg /1x 对照运行正常。v0.5.1 已移除数量代码写入和附近内存分配实现。自定义数量尚未交付，本版仅提供原版 1x。

离线检查覆盖三种弹体与资源包、原有飞鹰记录、固定数量、旧配置兼容、多个前移方向、每架飞机只调整一次、其他飞鹰/已投弹飞机/无效坐标拒绝，以及部分写入恢复。41 个独立预设模块验证通过。17550 种组合是次数、间隔、装填、弹体和前移距离的可选组合数，不代表全部实机测试。

详细证据见 `VALIDATION.json`。前移80米日志记录两次调用、共6架飞机的目标前移，用户确认覆盖改善。500 kg /1x/前移 0 米已确认正常投弹；其他组合和联机同步尚待验证。

## 禁用与开发

`enabled=0` 撤销默认携带与本插件拥有的战备字段，停止调整后续飞机。已有飞机保持已设置的目标；实体/组件映射留到进程退出，避免已创建实体持有失效指针。管理器禁用、Purge + Deploy 并重启后恢复原版。不会修改账户解锁或装备存档。

源码：`src/core.lua`；打包：`python tools/build.py`；离线检查：`python tests/test_runtime.py`。
