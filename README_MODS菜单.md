# 地毯轰炸 v0.5.1-menu

基于 `NativeCarpetBomb_v0.5.1.zip` 内的核心 Lua 适配。保留原有默认携带、载荷修复、禁用恢复和目标前移路径；每架投弹数量继续固定为 20 枚。

## 安装

关闭游戏，用 Arsenal / HD2MM 导入 `NativeCarpetBomb_v0.5.1-menu.zip` 替换旧版，启用核心并选择管理器预设，按加载器要求 Purge + Deploy 后重启。不要同时部署原版与此适配版。

需要 Bingus Shared Loader v18。游戏内 MODS 页面另外需要安装 **Bingus ModOptionsMenu API 1 / version 2**；Shared Loader 本身不提供菜单。没有菜单或菜单注册失败时，管理器预设和配置文件仍可使用。

## MODS 菜单

在 Esc → MODS → 原生地毯轰炸中设置，点击“应用”后写入配置文件，再由原有更新路径处理。第一行 `Language` 提供 `简体汉字` / `English`，只影响本模组文字，默认中文。应用语言后关闭并重新打开 Esc 菜单刷新；菜单会将 English 显示为 ENGLISH。

| 菜单项 | 含义 |
| --- | --- |
| 启用 | 开启默认携带；关闭沿用原有禁用恢复 |
| 使用次数来源 | 跟随管理器 / 有限次数 / 无限 |
| 使用次数 | 1–100；调整并应用会切换为有限次数 |
| 调用冷却来源 | 跟随管理器 / 自定义 |
| 调用冷却 | 0–1800 秒；调整并应用会切换为自定义 |
| 飞鹰装填来源 | 跟随管理器 / 保持原版 / 自定义 |
| 飞鹰装填冷却 | 0–1800 秒；调整并应用会切换为自定义；全部携带的飞鹰共用 |
| 炸弹类型 | 跟随管理器 / 原版空袭 / 地毯轰炸 200 kg / 飞鹰 500 kg |
| 目标前移来源 | 跟随管理器 / 自定义 |
| 投弹目标前移 | 0–300 米，步长 1 米；调整并应用会切换为自定义 |

滑块展示当前有效数值。“无限”时次数滑块展示管理器的有限预设（无有限预设则为 2）；“保持原版”时装填滑块展示管理器的自定义预设（没有则为 150），仅供切换为自定义时使用，不表示游戏的实时次数或实际原版装填秒数。来源与对应滑块同时更改时，按显示顺序应用，后面的滑块值决定最终配置。

更换炸弹类型后需重启游戏并进入新任务，让相应资源载入。次数和已在进行的计时可能需要新任务更新。前移仅影响后续新出动飞机；已出动飞机保留设置。0 米保留原落点。数量倍率不提供菜单项。

## 配置与兼容

配置仍是 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CarpetBombNative.cfg`，日志仍是同目录的 `CarpetBombNative.log`。各字段的 `manager` 保留独立含义，部署时的预设仍作为回退值；菜单选择自定义后仅覆盖该参数。恢复“跟随管理器”会把对应键保存为 `manager`。

旧配置缺少 `language` 时使用中文，其余参数保持不变。菜单保存保留原配置注释和未知键，并新增 `language=zh` 或 `language=en`。有效配置优先于菜单提供者的旧缓存；外部编辑有效配置后菜单同步。未点击应用的编辑不会被相同有效配置的同步清除。

保持原版装填保存为 `rearm=-1`，无限次数保存为 `uses=-1`，关闭保存为 `enabled=0`。`bomb_count` 仍强制为 20，旧数量覆盖仍被忽略。

本适配版本仅进行了离线 LuaJIT 和菜单 API 验证；游戏内显示、战斗和联机行为尚未实测。原版 v0.5.1 的既有实测记录见 `README_中文.md`，不代表菜单适配版已通过实机测试。

## 源码与检查

源码 `src/core.lua`；打包 `python tools/build.py`；测试 `python tests/test_runtime.py`。开发依赖沿用 `requirements-dev.txt`。默认检查使用菜单 API 模拟环境。要用真实提供者验证，将环境变量 `HD2_MOD_OPTIONS_MENU_SOURCE` 设置为已安装 ModOptionsMenu 的 Lua 源码路径后运行同一测试。真实 API 检查只执行注册、配置、应用与翻译函数，不安装原生 UI 更新 hook，也不接触运行中的游戏。第三方菜单源码不随本仓库分发。检查结果见包内 `VALIDATION.json`。
