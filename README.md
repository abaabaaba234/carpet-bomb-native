# Native CarpetBomb v0.5.8-cluster-test

Cluster fix candidate, preserving exactly 20 primary bombs per native aircraft and 8 native bomblets per primary. On 2026-10-16 the v0.5.7 diagnostic recorded 60 primaries turning into 480 secondary projectiles after their 0.35 s timer expired. The first sampled child group was about 576 m horizontally from the first aircraft target and 115 m above its elevation. This confirms early, distant splitting; it does not establish missing visual assets or exact impact locations. The user heard audio without seeing the effects near the beacon.

This candidate extends only individual, source-linked primary timers. A bounded lookup matches the projectile source pointer to currently identified native aircraft, rejects a source shared with ordinary Eagles, and requires a complete batch of 20 primaries per aircraft. Each primary receives one timer update estimated to split 30 m above beacon elevation, using its current velocity and the guarded native drag/gravity model. This is not a terrain raycast. Incomplete, ambiguous or changed batches are left alone. Shared projectile definitions, damage, eight-bomblet splitting, native 20-bomb scheduling and other bomb choices stay unchanged. A successful fuse update is consumed by game simulation; disabling stops future updates rather than undoing launched bombs.

51 offline groups cover source isolation, exact batch quantities, unchanged projectile definitions, rollback/concurrency and an independent numerical trajectory check. Actual source linkage, visible splitting, coverage and multiplayer in this new build still require gameplay verification. Bounded read-only diagnostic windows remain enabled. Close the game, import/deploy NativeCarpetBomb_v0.5.8-cluster-test.zip, retain Cluster / front-back / +80 m, restart into a new mission, and call once. Wait about 15 seconds and preserve the log before restarting. Expected evidence is Native cluster fuse adjusted: 3 aircraft, 60 primary bombs, followed by later splitting nearer target elevation.

Baseline feedback: 200 kg front/back at +80 m covered the beacon as intended; Napalm and Gas were usable, and other tested choices were reported usable. The cluster forward shift can still be skipped when native scheduling precedes the first flight observation; this candidate addresses fuse timing, not a guaranteed +80 m target translation.

The old concatenated expectation stopped the mod before granting CarpetBomb. Runtime checks remain enabled. Tests now use independently captured code windows, reproduce the old failure and pass after the fix. No fresh in-process or gameplay verification has been performed.
