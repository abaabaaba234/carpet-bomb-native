# Native CarpetBomb v0.5.9-cluster-test

Cluster timing follow-up; still 20 primary bombs per aircraft and 8 native bomblets per primary. The user tested v0.5.8 on 2026-10-16: all 60 source-linked primary timers were extended, but splitting felt late. Its log shows a first extension to 5.271 s; one sampled primary was only 27.1 m above target elevation with 1.126 s left, and some primary positions stayed unchanged while the timer continued. The initial forecast did not describe the actual flight closely enough.

v0.5.9 retains that extension only as a fallback, then samples the actual positions of those already identified native primaries every 0.05 s. When descending at or below 60 m above beacon elevation, it shortens a still-long timer to the native 0.35 s. The split therefore occurs later and lower than the sampling threshold. This is not terrain sensing. Coalesced reads are bounded to 128 tracked slots; recycled slots, changed source metadata, foreign countdowns, unavailable data and retired objects are relinquished. Disable or payload changes stop tracking, leaving any completed timer update for game simulation. Shared projectile definitions, damage, eight-bomblet splitting, native 20-bomb scheduling and other bomb choices stay unchanged.

55 offline groups pass, including replay of the independently saved v0.5.8 live positions/timers, source/slot/countdown lifetime checks, partial-write recovery and a 60-bomb read budget. Model agreement alone does not verify gameplay. Actual v0.5.9 timing, visible effects, coverage and multiplayer await gameplay verification. Close the game, import/deploy NativeCarpetBomb_v0.5.9-cluster-test.zip, keep Cluster / front-back / +80 m, restart into a new mission and call once. Wait about 15 seconds and preserve the log before restarting. Look for Native cluster height release and the completion count.

Earlier v0.5.7 diagnostics recorded 60 primaries splitting into 480 children after only about 0.35 s, far from the beacon. Baseline 200 kg front/back at +80 m, Napalm and Gas were reported usable. The cluster forward shift may still be skipped when native scheduling precedes the first flight sample; this change addresses splitting time, not guaranteed +80 m target translation.

v0.5.5 fixes the startup refusal in v0.5.4: the angle-read and angle-conversion instructions are at separate RVAs (+0x89F1A6 and +0x89F1B5). The old concatenated expectation stopped the mod before granting CarpetBomb. Runtime checks remain enabled. Tests now use independently captured code windows, reproduce the old failure and pass after the fix. No fresh in-process or gameplay verification has been performed.
